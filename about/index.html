關於本站

聖經原文解析是一個免費的研經工具，把聖經希伯來文、希臘文原文逐字解析，與恢復本（Recovery Version）中文經文對照在一起，協助讀者親自查考原文。

我們提供什麼

涵蓋新舊約全 66 卷、共 1,189 章。每一章有獨立的研經頁，呈現原文逐字對照、本章概要與恢復本經文對照； 每個原文字都附 Strong's 編號、字典原形（lemma）與詞形分析碼， 並可在收錄 14,197 條目的原文字典中追蹤同一個字在全本聖經的出現分布。

資料來源

  • 舊約原文：OSHB（Open Scriptures Hebrew Bible）／WLC（Westminster Leningrad Codex），開放授權。
  • 新約原文：SBLGNT 與 MorphGNT 的詞形標註，開放授權。
  • 恢復本經文：水流職事站（Living Stream Ministry, LSM）出版，屬 LSM 版權，透過官方 API 即時取得，本站不離線散布。
  • 地圖：Wikimedia Commons 公共領域古地圖（1853 Mitchell、1873 等），中文地名為對照標註、位置為近似標示。

編輯方法

原文逐字資料由上述開放授權底本經程式化處理（ETL）產生，包含 token 切分、Strong's 對應與詞形分析碼展開。 由於原文（OSHB／MorphGNT）與恢復本的分章分節慣例不同，本站對章節邊界做了系統化的重對映， 使逐章頁的原文與恢復本經文能正確對齊。字典的「出現於」章節索引由原文 token 反查生成。

與恢復本／LSM 的關係

本站是獨立的研經輔助工具，並非水流職事站（LSM）的官方網站，也不代表 LSM 的立場。 「恢復本」與「LSM」為其各自權利人之名稱與商標；恢復本經文依其官方授權規範使用。 若你需要購買或引用恢復本，請以 LSM 官方出版品為準。

補充：LSM 指 Living Stream Ministry（水流職事站），是聖經出版機構，與人工智慧或語言模型（LLM）無關。
